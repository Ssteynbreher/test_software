# Тестирование ПО

## Структура

- `ресурсы/` — задания к лабораторным работам.
- `labs/` — тесты, сценарии, настройки CI и вспомогательные скрипты.
- `output/` — подготовленные отчёты и экспортированные результаты.
- `.venv/` — Python-окружение предмета.

Перед изменением тестов определите лабораторную по файлу задания в `ресурсы/`; готовые файлы в `output/` сохраняйте как отдельные версии.
